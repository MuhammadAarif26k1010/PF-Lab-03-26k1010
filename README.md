## Introduction

This lab introduces GitHub and the basics of the C programming language.
It helps students learn how to create a repository, work with Markdown,
and understand basic C programming concepts.


## Objectives

1. To learn how to create and manage a GitHub repository.
2. To understand the basics of the C programming language.
3. To learn about C data types and format specifiers.
4. To understand input and output functions in C.
5. To practice Markdown documentation.


## C Topics Covered

- Data Types
- Format Specifiers
- Input/Output Functions
- Escape Sequences
- Precision
